# nvim config

Managed by [lazy.nvim](https://github.com/folke/lazy.nvim). Plugin specs live in `lua/plugins/*.lua` — lazy.nvim auto-imports them all. Config modules are in `lua/config/`.

## Structure

```
init.lua                  Entry point (settings, sources config/lsp, config/lazy)
lua/
  config/
    lazy.lua              Bootstrap + lazy.nvim setup
    lsp.lua               LSP server configs + LspAttach keymaps
  plugins/
    base16.lua            Colorscheme (base16-nvim + matugen)
    blink.lua             Completion engine (blink.cmp)
    conform.lua           Format-on-save (conform.nvim)
    indent-blankline.lua  Indentation guides
    lualine.lua           Statusline
    nvim-tree.lua         File explorer
    obsidian.lua          Obsidian vault integration
    smear.lua             Cursor animation
    telescope.lua         Fuzzy finder
    toggle-term.lua       Toggleable terminal
    treesitter.lua        Syntax highlighting
    trouble.lua           Diagnostics / LSP viewer
  matugen.lua             Dynamic theming (gitignored, regenerated by external daemon)
```

## Adding a language

Four things to check (in order):

1. **Binary** — ensure the LSP server, formatter, and treesitter parser are available (eventually via Nix).
2. **LSP** — add a `vim.lsp.config(...)` + `vim.lsp.enable(...)` in `lua/config/lsp.lua`.
3. **Formatter** — add a formatter entry in `lua/plugins/conform.lua`.
4. **Treesitter** — add the parser to `ensure_installed` in `lua/plugins/treesitter.lua`.

## Theming

The theme is base16-nvim with a custom palette (`lua/matugen.lua`). An external daemon (matugen) can send `SIGUSR1` to hot-reload colors without restarting Neovim.

## Notes

- Clipboard is synced with the system (`unnamedplus`).
- Leader key is `<Space>`.
- Indent width = 2 spaces.
- LSP servers configured: luals, rust-analyzer, typescript-language-server, nil, gopls.
